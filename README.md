# I Wanna Be In Class — CMC Run

A first-person pixel platformer: leave Kowloon Tong station and reach the CityU Creative Media Centre before 09:00.

**Play:** https://tinghualiu29-jpg.github.io/i-wanna-be-in-class/

Controls: WASD move, mouse look, Space jump / retry, Esc pause.

Built with Godot 4.7.2 (Compatibility renderer, single-threaded web export).
